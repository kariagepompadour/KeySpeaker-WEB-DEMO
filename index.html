NOTE

  • This is a screen demo of the device. BLE is never shown: the screen always says USB.実機の画面を再現したデモです。BLE は表示されません(接続表示は常に USB です)。
  • Even if a real Cardputer is connected to this computer, its key presses are not picked up by this page. Only this computer's keyboard (or the on-screen buttons) works here.実機をこのパソコンにつないでいても、実機のキー操作はこのページには反映されません。ここで使えるのは、このパソコンのキーボード(または画面のボタン)だけです。

AUDIO

Captures the sound this computer is playing. Press START, pick the tab (or screen) that makes the sound in the sharing dialog, and tick Share audio.このパソコンで再生中の音を取り込みます。START を押し、共有ダイアログで音を出しているタブ(または画面)を選び、「音声を共有」にチェックしてください。

  • Chrome / Edge: on Windows, "Entire screen" captures the whole system's sound; on Mac / Linux, share a "Tab".Chrome / Edge: Windows は「画面全体」で PC 全体の音、Mac / Linux は「タブ」の音を取り込めます。
  • The video is discarded. The sound is only analysed to drive the screen: it is not played again or sent anywhere (the source keeps playing as before).映像は使わず捨てます。音は画面に反応するためだけに解析し、再生も送信もしません(取り込み元の音はそのまま鳴ります)。
  • Phone browsers cannot capture audio.スマホのブラウザは音の取り込みに対応していません。
  • START and Full screen are buttons for this web version only, not device keys.START と全画面はWEB版だけのボタンです。実機のキーではありません。

After the opening screen, the screen you used last comes up, as on the device (remembered in this browser; flight mode the first time).
In measure mode, a minute with no key and no sound brings back the resting emblem (any key wakes it). The equalizer swaps in by itself every minute and between songs.
Volume, mute, boost and bass cut change only what the screen shows, not the PC's volume or sound. In keyboard mode the arrows, Esc, F1–F12, Delete and copy/paste go to the computer on the device; this web version does not send them.オープニング画面のあとは、実機と同じく前回使っていた画面が表示されます(このブラウザに記憶。初回は飛行モード)。
計測モードで 1 分間、キーも音もないと待機中のエンブレムに戻ります(どれかキーで復帰)。EQ は 1 分ごと・曲の切れ目で自動的に入れ替わります。
音量・ミュート・ブースト・低音カットは画面の表示だけが変わります(PC の音量や音は変わりません)。キーボードモードの矢印・Esc・F1〜F12・Delete・コピー&ペーストは、実機ではPCへ送られます(このWEB版では送信しません)。
