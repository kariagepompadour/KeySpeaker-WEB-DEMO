KeySpeaker WEB DEMO

Terrain grows from the sound your computer is playing (or the sound the microphone hears), and a fighter flies over it. The Cardputer ADV screen (240×135), reproduced as it is.パソコンで鳴っている音(またはマイクが拾った音)に反応して地形ができ、宇宙船が進みます。Cardputer ADV の画面(240×135)をそのまま再現しています。

  • Even if a real Cardputer is connected to this computer, its key presses are not picked up by this page. Only this computer's keyboard (or the on-screen buttons) works here.実機をこのパソコンにつないでいても、実機のキー操作はこのページには反映されません。ここで使えるのは、このパソコンのキーボード(または画面のボタン)だけです。

AUDIO

On a computer, press START to capture the sound it is playing: pick the tab (or screen) that makes the sound in the sharing dialog and tick Share audio. Or press MIC START to use the microphone. On a phone, press MIC START.パソコンでは START を押すと、再生中の音を取り込みます(共有ダイアログで音を出しているタブまたは画面を選び、「音声を共有」にチェック)。MIC START を押すと、マイクの音を取り込みます。スマホでは MIC START を押してください。

  • Chrome / Edge: on Windows, "Entire screen" captures the whole system's sound; on Mac / Linux, share a "Tab".Chrome / Edge: Windows は「画面全体」で PC 全体の音、Mac / Linux は「タブ」の音を取り込めます。
  • The video is discarded. The sound is only analysed to drive the screen: it is not played again or sent anywhere (the source keeps playing as before).映像は使わず捨てます。音は画面に反応するためだけに解析し、再生も送信もしません(取り込み元の音はそのまま鳴ります)。
  • Safari and Firefox cannot share audio, so use Chrome or Edge. Play the music in a different tab of that same browser.Safari と Firefox は音を共有できません。Chrome か Edge を使い、音楽は同じブラウザの別のタブで鳴らしてください。
  • Test sound plays a synthetic song into the screen (nothing is played through the speakers), so you can see it without sharing any sound. The line under the buttons shows what the page receives.テスト音は合成した曲を画面に流します(スピーカーからは鳴りません)。音を共有しなくても動きが見られます。ボタンの下の1行は、ページが受け取っている音の状態です。
  • Phone browsers cannot capture the sound the phone itself plays, so START is hidden there and MIC START is the main button: the screen reacts to what the microphone hears.スマホのブラウザは、スマホ自身が再生している音を取り込めません。そのため START は表示されず、MIC START が主なボタンになります(マイクが拾った音に画面が反応します)。
  • MIC START asks the browser for the microphone only when you press it, and needs the page to be opened over HTTPS. The sound is only analysed to drive the screen: it is not played through the speakers, recorded or sent anywhere. If you refuse, allow the microphone in the browser's site settings and press it again. If the microphone is cut off (screen lock, a call, another app), the page waits a few seconds, then stops it and asks you to press MIC START again. START, MIC START and Test sound stop one another.MIC START を押したときだけ、ブラウザにマイクの使用許可を求めます(ページを HTTPS で開く必要があります)。音は画面に反応するためだけに解析し、スピーカーからは鳴らさず、録音も送信もしません。許可しなかった場合は、ブラウザのサイト設定でマイクを許可してから、もう一度押してください。画面ロック・通話・ほかのアプリの使用などでマイクが止まった場合は、数秒待ってから停止し、もう一度 MIC START を押すよう案内します。START・MIC START・テスト音は、どれか1つだけが動き、選ぶと他は止まります。
  • START, MIC START and Full screen are buttons for this web version only, not device keys.START・MIC START・全画面はWEB版だけのボタンです。実機のキーではありません。

After the opening screen, the screen you used last comes up, as on the device (remembered in this browser; flight mode the first time).
In measure mode, a minute with no key and no sound brings back the resting emblem (any key wakes it). The equalizer swaps in by itself every minute and between songs.
Volume, mute, boost and bass cut change only what the screen shows, not the PC's volume or sound. In keyboard mode the arrows, Esc, F1–F12, Delete and copy/paste go to the computer on the device; this web version does not send them.オープニング画面のあとは、実機と同じく前回使っていた画面が表示されます(このブラウザに記憶。初回は飛行モード)。
計測モードで 1 分間、キーも音もないと待機中のエンブレムに戻ります(どれかキーで復帰)。EQ は 1 分ごと・曲の切れ目で自動的に入れ替わります。
音量・ミュート・ブースト・低音カットは画面の表示だけが変わります(PC の音量や音は変わりません)。キーボードモードの矢印・Esc・F1〜F12・Delete・コピー&ペーストは、実機ではPCへ送られます(このWEB版では送信しません)。
